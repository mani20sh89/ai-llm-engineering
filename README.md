# AI & LLM Engineering Portfolio

**Author:** Manish Kundu

## About This Repository

A collection of hands-on projects exploring Large Language Models (LLMs), Generative AI, and AI application development using Python.

The projects cover LLM integration, prompt engineering, web scraping, tokenization, conversation management, and working with both cloud-based and locally hosted AI models.

## Projects

### 1. AI Website Summariser

A Python application that extracts webpage content and generates concise summaries using the OpenAI API.

**Technologies:** Python, OpenAI API, Requests, Beautiful Soup, Jupyter Notebook.

[View Project](./ai-website-summariser-manish-kundu.ipynb)

### 2. Chat Completion APIs

A Python notebook demonstrating chat completion API integration with OpenAI, Google Gemini, and local Ollama models.

**Technologies:** Python, OpenAI API, Gemini API, Ollama, Requests, Jupyter Notebook.

[View Project](./ai-chat-completion-apis-manish-kundu.ipynb)

### 3. Tokenization and Conversation State

A Python notebook exploring tokenization, token IDs, chat completion requests, and how conversation history provides context across API calls.

**Technologies:** Python, OpenAI API, tiktoken, Jupyter Notebook.

[View Project](./ai-tokenization-and-conversation-state-manish-kundu.ipynb)

### 4. AI Company Brochure Generator

A Python application that extracts relevant information from company websites and generates structured company brochures using locally hosted LLMs through Ollama. Supports DeepSeek and Llama models, web scraping, prompt engineering, Markdown generation, and streaming responses.

**Technologies:** Python, Ollama, DeepSeek, Llama, OpenAI-compatible API, Web Scraping, Jupyter Notebook.

[View Project](./ai-company-brochure-generator-manish-kundu.ipynb)

### 5. AI Technical Question Explainer

A Python notebook that uses OpenAI and local Ollama models to explain technical questions through AI-generated responses. Demonstrates chat completion APIs, prompt engineering, and streaming responses.

**Technologies:** Python, OpenAI API, Ollama, Llama 3.2, Jupyter Notebook.

[View Project](./ai-technical-question-explainer-manish-kundu.ipynb)
